## 3. Open product questions

- **#29:** reject a non-integer `account` (report's fix), or accept a numeric string `"5"` as 5? `-1` and `1.5` must be refused either way.
- **#21:** BIP-388 lists KEY as `KP/**` only (no literal keys), yet the `--template` path already emits the literal NUMS key in `description_template`; make `--descriptor` agree (fix used), or make both refuse?
- **#49:** refuse a depth-0 top-level `xpub` when no single-sig block exists (fix used), or also refuse when any block exists?
- **#20:** keystore label scheme (`"{name} {i}"` in the scratch fix vs `"{name}-{i}"`); Electrum export already uses `-N` and Electrum import strips it (#23), so `-N` would round-trip.
- **#22:** in descriptor mode count only keys with an xpub (scratch fix) or all keys including a NUMS internal key?
- **#19:** BIP-45 has no coin-type component; is "network from the xpub version, no heterogeneity check beyond equal paths" the intended rule?
- **#57:** refuse the mismatched-script pair (fix used: falls through to the existing fixed-step floor reject) or import the two entries separately?
