`crates/ms-codec/src/payload.rs` exposes non-exhaustive `Payload`/`PayloadKind`: `Entr(Vec<u8>)`, `Mnem { language, entropy }`, and `Preimage(Zeroizing<[u8; 32]>)`. `crates/ms-codec/src/consts.rs` and `crates/ms-codec/src/envelope.rs` implement prefixes **0x00/0x02/0x03** respectively. Direct `seed`/`xprv`/`prvk` remain rejected. A preimage carries neither hash algorithm nor derivation method; `HashKind`/`DigestBytes` in `crates/ms-codec/src/hashlock.rs` supply explicit digest handling.

`crates/ms-codec/src/shares.rs::combine_shares` rejects index-`s` inputs and duplicate indices, reconstructs from exactly `k` shares, checks additional shares against that polynomial, then validates the recovered payload. Interpret payload prefixes after reconstruction; preserve full share strings through recovery. `Threshold::new` accepts 2–9; `encode_shares` requires `k ≤ n ≤ 31`. **`combine_shares` returns `Tag::ENTR` even for Preimage**: dispatch by payload kind.

Entr/Mnem buffers and returned strings require caller-owned scrubbing; `Payload`’s derived `Debug` is not redaction. `crates/ms-cli/src/cmd/repair.rs` reports applied correction as an **unverified candidate, exit 4**. Entr omits language; Mnem’s wire language is authoritative through `crates/ms-cli/src/cmd/payload_lang.rs`. The separately supplied passphrase remains outside the backup payload. Preimages must never enter mnemonic derivation.

Both wire-version fields remain **zero**: `crates/mk-codec/src/bytecode/header.rs` and `crates/mk-codec/src/string_layer/header.rs`. `crates/mk-codec/src/bytecode/xpub_compact.rs` stores 73 bytes: version, parent fingerprint, chain code, compressed point. `reconstruct_xpub` derives depth/child from the origin path; `crates/mk-codec/src/bytecode/encode.rs` rejects disagreement before discarding those fields. `crates/mk-codec/src/string_layer/chunk.rs` derives a 20-bit ID from canonical-bytecode SHA256 and verifies a separate four-byte cross-chunk hash.
