## 3. Open product questions

- #15: what is the maximum dice `--length`? BIP-85 text says `1 <= rolls <= 2^32 - 1`, but `rolls` is a hardened path index so BIP-32 already refuses `>= 2^31` (`child number ... invalid`). Choose the cap and the refusal wording.
- #24: should plain `sh(sortedmulti(...))` also default to `1'` (bundle maps every `Tag::Sh` to 1')? Should `xpub-search` print this notice at all, given the annotation is not consumed?
- #32: refuse (BadInput) or clamp an account window that reaches 2^31, including `min + number_of_accounts` crossing it?
- #33/#34: GUI `--template` for `verify-bundle` with `--md1` / `--bundle-json` / positional strings: required (safe for keyed inputs) or optional (right for template-form bundles)? The schema cannot tell them apart. For `bundle --import-json` the CLI forbids `--template` outright, so "required" is plainly wrong there.
- #36: fix the mapper, or delete the unreachable post-dispatch check?
- #56: refuse a non-master xprv (report's fix) or warn and continue; and should the refusal tell the holder to supply the seed phrase or master xprv?
- #48: tolerate only leading/trailing blanks (BIP-322 path) or also wrapped base64 lines?
