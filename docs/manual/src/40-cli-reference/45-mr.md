# `mr` (mr-cli) reference

The standalone CLI for the Refugium mr1 format (mnemonic-refugium /
mr-codec). An mr1 card describes a whole set of wallets: one template
(a BIP-388 wallet policy), an epoch axis that moves its deadlines
forward, and a table of slots (rows) that change the template per
wallet. Each wallet of the set is a *member* (e, s): epoch e, slot s.
The card also carries the (0, 0) member as an md1 card.

This chapter mirrors the read-side verbs of mnemonic-refugium's
`mr-cli`: `verify`, `decode`, `repair`, `member`, `address`, `current`
and `units`. `create`, `upgrade` and `export` are **not yet available**:
they parse no arguments and exit 1 with `<verb>: not implemented yet`.

:::primer
A *slot* is a row of the card's slot table: slot 0 is the template as
written, and each further slot changes some of its units (switches a
branch off, shifts a deadline, adds a wait). An *epoch* moves every
deadline of the template forward by the card's delta, so the same slot
at a later epoch is a new wallet with later deadlines. `current` tells
you which epoch to use now; `member` and `address` hand out that member.
:::

Every subcommand below accepts `--help` (`-h`) for inline help.

## Conventions

| Topic | Rule |
|---|---|
| Card input | The positional `<mr1>...` is one card: a single `mr1` string, or every string of a chunk set, in order. A chunk set is always one card, never several |
| Checksums | Every reading verb **verifies only**: a string that is not a valid codeword is refused (`the mr1 checksum does not verify`), never corrected silently. Correction is `mr repair`'s job |
| Network | `--network <NETWORK>` is global: `main` (the default; `mainnet` is accepted as an alias), `signet`, `testnet` or `regtest`. It picks the address format, `xpub` or `tpub`, the tip anchor and the coin type. Any other value is a usage error |
| Tip | The tool never reads the machine's clock. Every verb that measures a deadline takes the chain tip as `--height H --time T` (the median time past, unix seconds; `--time` takes any u32) and prints `tip = <height>, ≈ <date>; this must be the current tip` first. On mainnet a tip whose height and time disagree with the release's anchor by more than 180 days is refused unless `--accept-tip`; off mainnet it only warns |
| Numbers | Printed numbers carry thousands separators (`1,260,000`), except in script text, command lines, flag values, indexes, epochs and hex ids |
| Streams | Results go to stdout; warnings go to stderr as `warning: …`; errors print as `mr: <message>` |
| Secrets | Seeds, entropy, words and private keys never appear in output or errors |

### Exit codes

| Code | Meaning |
|---|---|
| `0` | success |
| `1` | refused or failed (a guardrail, a check, a key that does not fit) |
| `2` | usage error (unknown flag, bad value, missing argument); `mr repair`: nothing could be corrected |
| `5` | `mr repair` only: the strings were corrected |

### Keys and seeds

`verify`, `member` and `address` take the set's keys in one of these forms:

| Form | Meaning |
|---|---|
| `--keys <mk1…>` | an mk1 plate (a chunked plate's strings in one value, separated by spaces) |
| `--keys '[fp/path]xpub'` | a record: a key in `verify`; in `member` and `address` it only confirms a seat that a seed supplies; `member --for-spend` refuses one |
| `--keys '@i=<key>'` | the key bound to seat `@i`, in the card's stored numbering |
| `--keys-file <file>` | one key per line (`@i=<card>` or the key alone), a chunked plate's strings on consecutive lines; blank lines and `#` comments are skipped |
| `--seeds <seeds>` | ms1 plates or BIP-39 words, comma-separated, seed 1 first |

## `mr verify`

Re-read an engraved card and check it against ids, keys or seeds. With
keys or seeds it prints the seat each one filled (`plate 2 → seat @2`,
with the seat check `sc:…`) and fails on a stub mismatch.

### Synopsis

```sh
mr verify [OPTIONS] <mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1>...` | the card's strings (one, or each chunk of a chunked card) |
| `--set-id <ID>` | fails unless the card's set id is ID (hex) |
| `--digest <D>` | fails unless the card digest is D (hex): proves this engraving |
| `--against <md1>` | checks that member (0, 0) matches this md1 card (its strings in one value, separated by spaces) |
| `--keys <mk1…\|records>...` | keys: mk1 plates or `[fingerprint/path]xpub` records, each optionally `@i=`-bound |
| `--keys-file <file>` | a file of keys: one `@i=<card>` per line, chunked cards as consecutive strings |
| `--seeds <seeds>...` | seeds: ms1 plates or BIP-39 words, comma-separated, in order (seed 1 first) |
| `--seed-language <n>=<lang>` | the wordlist of seed n (english, japanese, korean, spanish, chinese-simplified, chinese-traditional, french, italian, czech, portuguese) |
| `--accept-seed-language <n>` | consent to use seed n in a language other than English |
| `--network <NETWORK>` | see Conventions |

## `mr decode`

Print everything an mr1 card holds: the template, delta and anchors,
set id, card digest, the (0, 0) policy id, stub and md1 card (as md1
chunks when it is over 80 symbols), the seat map, the units, each slot
(its locks, what it removes and drops, whether it is open or a
lock-up), the set end, each slot's deadlines at epoch 0, and a bundle
checklist when the card lists other cards. It takes no keys.

### Synopsis

```sh
mr decode [OPTIONS] <mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1>...` | the card's strings |
| `--network <NETWORK>` | see Conventions |

## `mr repair`

Correct up to 4 substituted characters per mr1 string. A chunk set is
repaired as one card, atomically: one uncorrectable string fails the
whole call with no output. A mixed-case string, and a string over 93
symbols after `mr1`, are refused before any correction. Exit `0`:
nothing to correct; `5`: corrected (a repair report and the corrected
strings on stdout); `2`: not correctable.

### Synopsis

```sh
mr repair [OPTIONS] <mr1 strings>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1 strings>...` | the strings to correct (one card: one string, or its chunk set) |
| `--network <NETWORK>` | see Conventions |

## `mr member`

Print one member (e, s) of the set as split-chain descriptors, an md1
card or a BIP 388 wallet policy. It runs every hand-out guardrail
(open, clamped, reorder, lock-up and its window, deadline, horizon),
prints the slot's description, lock dates, costs and minimum deposit,
and warns when one key alone spends. With `--for-spend` it prints the
member as the source of a sweep instead: `importdescriptors` JSON on
stdout and the step-by-step Core recipe on stderr.

### Synopsis

```sh
mr member [OPTIONS] --epoch <E> --slot <S> --height <H> --time <T> <mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1>...` | the card's strings |
| `--epoch <E>` | the epoch E |
| `--slot <S>` | the slot S |
| `--keys <mk1…\|records>...` | keys (see Keys and seeds) |
| `--keys-file <file>` | a file of keys |
| `--seeds <seeds>...` | seeds: ms1 plates or BIP-39 words, comma-separated, in order |
| `--seed-language <n>=<lang>` | the wordlist of seed n |
| `--accept-seed-language <n>` | consent to use seed n in a language other than English |
| `--height <H>` | the tip's block height |
| `--time <T>` | the tip's median time past, unix seconds (any u32) |
| `--accept-tip` | accept a tip whose height and time disagree with this release's anchor by more than 180 days |
| `--as <form>` | the output form: `descriptor` (split-chain, checksummed descriptors; the default), `md1` (the member's md1 card, chunked if needed) or `policy` (a BIP 388 wallet policy for signer registration) |
| `--open-slot` | hand out an open member (some key spends sooner than the template allows) |
| `--accept-clamped` | accept a lock clamped at its minimum by a shift, to-deadline or add-deadline (prints "spendable immediately by") |
| `--reorder-slot` | accept a member whose paths open in another order than at slot 0 |
| `--lockup-slot` | hand out a lock-up slot (no path spends without a lock) |
| `--lockup-no-window` | accept a lock-up window shorter than `--min-lead` |
| `--accept-deadline` | accept a deadline already past or closer than `--min-lead` |
| `--beyond-horizon` | hand out a member beyond the heir's default scan |
| `--min-lead <L>` | the minimum lead, in days (default 30) |
| `--for-spend` | print the member as the source of a spend: `importdescriptors` JSON (inactive, timestamp 0) on stdout, the spend recipe on stderr; skips the deadline and horizon guardrails and the hand-out consents |
| `--accept-stub-mismatch` | seat a plate whose policy-id stub is not this card's |
| `--accept-unconfirmed-seeds` | use seeds nothing on the card confirms |
| `--min-deposit <sats>` | the minimum sensible deposit to print, in sat (replaces the reference figure) |
| `--compromised` | declare this card's hot device lost or stolen: refuses unless `--for-spend`, which prints the destination rule |
| `--network <NETWORK>` | see Conventions |

`--as md1` prints the member's md1 card and a `md … --seat '@m=…'`
line per seated mk1 plate; `--for-spend` refuses it. `--as policy`
sends a signer only a registrable policy, printing on stderr each
seat's xpub text and seat check and naming the seats filled only from
the card. On a card with a filled hot seat, a run without
`--compromised` ends with a one-line reminder to rerun with it if the
hot device was ever lost.

## `mr address`

Derive one address of a member, to check a receive or presigned-move
destination before using it. Every run prints "before the first
deposit to this set, check this address on a signer's screen". It
prints every hand-out refusal, the open one first; at a row other than
0 the open refusal names the slot-0 paths the row locks and the rows
that qualify instead. `--compromised` refuses at every row.

### Synopsis

```sh
mr address [OPTIONS] --epoch <E> --slot <S> --index <I> --height <H> --time <T> <mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1>...` | the card's strings |
| `--epoch <E>` | the epoch E |
| `--slot <S>` | the slot S |
| `--index <I>` | the address index I (an index of 1000 or more warns: the heir's scan may not reach it) |
| `--keys <mk1…\|records>...` | keys (see Keys and seeds) |
| `--keys-file <file>` | a file of keys |
| `--seeds <seeds>...` | seeds: ms1 plates or BIP-39 words, comma-separated, in order |
| `--seed-language <n>=<lang>` | the wordlist of seed n |
| `--accept-seed-language <n>` | consent to use seed n in a language other than English |
| `--height <H>` | the tip's block height |
| `--time <T>` | the tip's median time past, unix seconds (any u32) |
| `--accept-tip` | accept a tip whose height and time disagree with this release's anchor by more than 180 days |
| `--change` | the change chain (`/c+1/*`) instead of the receive chain |
| `--open-slot` | hand out an open member |
| `--accept-clamped` | accept a lock clamped at its minimum by a shift, to-deadline or add-deadline |
| `--reorder-slot` | accept a member whose paths open in another order than at slot 0 |
| `--lockup-slot` | hand out a lock-up slot |
| `--lockup-no-window` | accept a lock-up window shorter than `--min-lead` |
| `--accept-deadline` | accept a deadline already past or closer than `--min-lead` |
| `--beyond-horizon` | hand out a member beyond the heir's default scan |
| `--min-lead <L>` | the minimum lead, in days (default 30) |
| `--accept-stub-mismatch` | seat a plate whose policy-id stub is not this card's |
| `--accept-unconfirmed-seeds` | use seeds nothing on the card confirms |
| `--min-deposit <sats>` | the minimum sensible deposit to print, in sat |
| `--compromised` | declare this card's hot device lost or stolen: refuses at every row |
| `--network <NETWORK>` | see Conventions |

**Presigned moves** stay broadcastable until their inputs are spent and
do not protect coins past the epoch deadline: migrate to a fresh epoch
before leaving, and on return treat the transaction as live until its
coins are moved. Their fee is fixed at signing, so they need a fee
ladder or a P2A anchor. (`mr address --help` prints this advisory.)

## `mr current`

Find the nearest epoch whose every absolute lock, in slot S (default
0), is at least a lead L away, each kind in its own units (a block
counts 9 minutes). Locks set by `open` are ignored; a slot with no
other absolute lock is measured by the card's deadline functions, and
the answer then changes only the branch. Without `--slot`, each
own-wallet row is answered too (`wallet at slot s: epoch E`).

It also prints, for each path of the answered member with a relative
lock, `path <keys> opens about N days after each deposit confirms`,
warning when that wait is shorter than your lead, and the migration
rule: every row's funds move to the same slot of the new epoch, and
only an open row's go to slot 0.

It refuses when no epoch meets the lead: `no epoch of slot S meets
lead L; a lead of at most <L′> still reaches epoch <E>` while one
still meets `--min-lead`, else `this slot ends at <date>; move to a new
set on new origin paths`. Past the heir's default scan it answers the
last epoch of the scan and prints the lead achieved (`lead 9.4 years:
the most the heir's default scan covers`), or refuses `this slot ends
within the heir's scan: move to a new set` when that lead is below
`--min-lead`. An epoch-less card answers epoch 0 for any lead. At a
tip past 2038-01-19 a slot whose member carries a time lock has no
epoch, and `current` answers only the other slots. It takes no
`--compromised` and prints no reminder.

### Synopsis

```sh
mr current [OPTIONS] --height <H> --time <T> --lead <L> <mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1>...` | the card's strings |
| `--height <H>` | the tip's block height |
| `--time <T>` | the tip's median time past, unix seconds (any u32) |
| `--accept-tip` | accept a tip whose height and time disagree with this release's anchor by more than 180 days |
| `--lead <L>` | the lead: how far every absolute lock must be from the tip (`2y`, `26w`, `30d`, `36h`; a bare number is days; a block counts 9 minutes). Required |
| `--slot <S>` | the slot S (default 0; without it, each own-wallet row is answered too) |
| `--min-lead <L>` | the minimum lead: never offers a lead below it (default 30 days); same syntax as `--lead` |
| `--beyond-horizon` | answer an epoch beyond the heir's default scan |
| `--network <NETWORK>` | see Conventions |

### Worked example

```sh
mr current mr1… --network testnet --height 1000000 --time 1900000000 --lead 5y
# tip = 1,000,000, ≈ 2030-03-17; this must be the current tip
# slot 0: epoch 1
# funds at slot 0 migrate to slot 0 of epoch 1; every row keeps its slot, …
```

## `mr units`

List the units of a template or card in order, each with its keys and
locks and whether `off`, add-wait and add-deadline are available there,
marking a unit whose `off` would be refused.

### Synopsis

```sh
mr units [OPTIONS] <template|mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<template\|mr1>...` | a template (one argument), or a card (one `mr1` string or its chunk set) |
| `--network <NETWORK>` | see Conventions |
