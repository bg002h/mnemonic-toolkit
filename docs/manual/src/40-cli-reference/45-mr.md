# `mr` (mr-cli) reference

The standalone CLI for the Refugium mr1 format (mnemonic-refugium /
mr-codec). An mr1 card describes a whole set of wallets: one template
(a BIP-388 wallet policy), an epoch axis that moves its deadlines
forward, and a table of slots (rows) that change the template per
wallet. Each wallet of the set is a *member* (e, s): epoch e, slot s.
The card also carries the (0, 0) member as an md1 card.

This chapter mirrors the read-side verbs of mnemonic-refugium's
`mr-cli`: `verify`, `decode`, `repair`, `member`, `address`, `current`,
`units` and the heir's `export`. `create` and `upgrade` are **not yet
available**: they parse no arguments and exit 1 with `<verb>: not
implemented yet`.

:::primer
A *slot* is a row of the card's slot table: slot 0 is the template as
written, and each further slot changes some of its units (switches a
branch off, shifts a deadline, adds a wait). An *epoch* moves every
deadline of the template forward by the card's delta, so the same slot
at a later epoch is a new wallet with later deadlines. `current` tells
you which epoch to use now; `member` and `address` hand out that member.
:::

Every subcommand below accepts `--help` (`-h`) for inline help. Each Flags table quotes `mr <verb> --help` verbatim.

## Conventions

| Topic | Rule |
|---|---|
| Card input | The positional `<mr1>...` is one card: a single `mr1` string, or every string of a chunk set, in order. A chunk set is always one card, never several |
| Checksums | Every reading verb **verifies only**: a string that is not a valid codeword is refused (`the mr1 checksum does not verify`), never corrected silently. Correction is `mr repair`'s job |
| Network | `--network <NETWORK>` is global: `main` (the default; `mainnet` is accepted as an alias), `signet`, `testnet` or `regtest`. It picks the address format, `xpub` or `tpub`, the tip anchor and the coin type. Any other value is a usage error |
| Tip | The tool never reads the machine's clock. Every verb that measures a deadline takes the chain tip as `--height H --time T` (the median time past, unix seconds; `--time` takes any u32) and prints `tip = <height>, ≈ <date>; this must be the current tip` first. On mainnet a tip whose height and time disagree with the release's anchor by more than 180 days is refused unless `--accept-tip`; off mainnet it only warns. `member --for-spend` runs no tip check, so recovery is never blocked by it: it prints only the tip line |
| Numbers | Printed numbers carry thousands separators (`1,260,000`), except in script text, command lines, flag values, indexes, epochs and hex ids |
| Streams | Results go to stdout; warnings go to stderr as `warning: …`; errors print as `mr: <message>`. A reader that closes the pipe early (`mr decode … \| head -1`) only stops the output: the exit code is the verb's own. Any other write error on stdout (a full disk, `> /dev/full`), from a verb or `--help`, prints `mr: cannot write the output: <error>` and exits 1. A stdout closed outright (`>&-`) behaves as `> /dev/null`: the output is discarded and the exit code is the verb's own |
| Secrets | `mr` never prints a private key, entropy or an ms1 seed string. It prints seed words in one case only: for each seed that `--seeds` gives as BIP-39 words, stderr carries `seed <n> read as <language>: <words>` once, so the words can be checked against the backup. Treat stderr as secret whenever `--seeds` holds words. A card argument that does not start `mr1` is never echoed: seed words (spaced or comma-joined), an ms1 string, an mk1 string or an md1 string is refused by every verb, naming only what it looks like, e.g. `a card argument looks like seed words (<n> words, not echoed): seeds go in --seeds, and a card is its mr1 strings`. `member`, `address` and `current` refuse any other non-`mr1` value the same way, quoting only a bare integer (the `--epoch`/`--slot` hint); `units` reads a non-`mr1` argument as a template: one with no `(` is never a template and is never quoted, only named by its kind (an extended private key, a WIF or base58 key, hex, seed words joined by any punctuation, or a bare word), and a template's parse error replaces any such part by its kind while still quoting a fragment name. A usage error never echoes a seed-looking argument either (a phrase typed without its verb, as a flag's value, or as the `<lang>` of `--seed-language 1=<lang>`): it shows `<seed words (<n> words, not echoed)>` in its place, and keeps the verb and flag names as they are. The command line itself (shell history, the process list) is outside `mr`'s reach |

### Exit codes

| Code | Meaning |
|---|---|
| `0` | success |
| `1` | refused or failed (a guardrail, a check, a key that does not fit) |
| `2` | usage error (unknown flag, bad value, missing argument); `mr repair`: nothing could be corrected |
| `5` | `mr repair` only: the strings were corrected |

### Keys and seeds

`verify`, `member` and `address` take the set's keys in one of these forms:

| Form | Meaning |
|---|---|
| `--keys <mk1…>` | an mk1 plate (a chunked plate's strings in one value, separated by spaces) |
| `--keys '[fp/path]xpub'` | a record: a key in `verify`; in `member` and `address` it only confirms a seat that a seed supplies; `member --for-spend` refuses one |
| `--keys '@i=<key>'` | the key bound to seat `@i`, in the card's stored numbering |
| `--keys-file <file>` | one key per line (`@i=<card>` or the key alone), a chunked plate's strings on consecutive lines; blank lines and `#` comments are skipped |
| `--seeds <seeds>` | ms1 plates or BIP-39 words, comma-separated, seed 1 first |

## `mr verify`

Re-read an engraved card and check it against ids, keys or seeds. With
keys or seeds it prints the seat each one filled (`plate 2 → seat @2`,
with the seat check `sc:…`) and fails on a stub mismatch.

### Synopsis

```sh
mr verify [OPTIONS] <mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1>...` | The card's strings (one, or each chunk of a chunked card) |
| `--network <NETWORK>` | Network: main (default; `mainnet` is accepted too), signet, testnet or regtest [default: main] |
| `--set-id <ID>` | Fails unless the card's set id is ID (hex) |
| `--digest <D>` | Fails unless the card digest is D (hex): proves this engraving |
| `--against <md1>` | Checks that member (0, 0) matches this md1 card (its strings in one value, separated by spaces) |
| `--keys <mk1…\|records>...` | Keys: mk1 plates (a chunked plate's strings in one value, separated by spaces) or `[fingerprint/path]xpub` records, each optionally `@i=`-bound |
| `--keys-file <file>` | A file of keys: one `@i=<card>` per line, chunked cards as consecutive strings |
| `--seeds <seeds>...` | Seeds: ms1 plates or BIP-39 words, comma-separated, in order (seed 1 first) |
| `--seed-language <n>=<lang>` | The wordlist of seed n: `<n>=<lang>` (english, japanese, korean, spanish, chinese-simplified, chinese-traditional, french, italian, czech, portuguese) |
| `--accept-seed-language <n>` | Consent to use seed n in a language other than English |

## `mr decode`

Print everything an mr1 card holds: the template, delta and anchors,
set id, card digest, the (0, 0) policy id, stub and md1 card (as md1
chunks when it is over 80 symbols), the seat map, the units, each slot
(its locks, what it removes and drops, whether it is open or a
lock-up), the set end, each slot's deadlines at epoch 0, and a bundle
checklist when the card lists other cards. It takes no keys.

### Synopsis

```sh
mr decode [OPTIONS] <mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1>...` | The card's strings (one, or each chunk of a chunked card) |
| `--network <NETWORK>` | Network: main (default; `mainnet` is accepted too), signet, testnet or regtest [default: main] |

## `mr repair`

Correct up to 4 substituted characters per mr1 string. A chunk set is
repaired as one card, atomically: one uncorrectable string fails the
whole call with no output. A mixed-case string, and a string over 93
symbols after `mr1`, are refused before any correction. Exit `0`:
nothing to correct; `5`: corrected (a repair report and the corrected
strings on stdout); `2`: not correctable.

### Synopsis

```sh
mr repair [OPTIONS] <mr1 strings>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1 strings>...` | The strings to correct (one card: one string, or its chunk set) |
| `--network <NETWORK>` | Network: main (default; `mainnet` is accepted too), signet, testnet or regtest [default: main] |

## `mr member`

Print one member (e, s) of the set as split-chain descriptors, an md1
card or a BIP 388 wallet policy. It runs every hand-out guardrail
(open, clamped, reorder, lock-up and its window, deadline, horizon),
prints the slot's description, lock dates, costs and minimum deposit,
and warns when one key alone spends. With `--for-spend` it prints the
member as the source of a sweep instead: `importdescriptors` JSON on
stdout and the step-by-step Core recipe on stderr.

### Synopsis

```sh
mr member [OPTIONS] --epoch <E> --slot <S> --height <H> --time <T> <mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1>...` | The card's strings (one, or each chunk of a chunked card) |
| `--epoch <E>` | The epoch E |
| `--network <NETWORK>` | Network: main (default; `mainnet` is accepted too), signet, testnet or regtest [default: main] |
| `--slot <S>` | The slot S |
| `--keys <mk1…\|records>...` | Keys: mk1 plates (a chunked plate's strings in one value, separated by spaces) or `[fingerprint/path]xpub` records, each optionally `@i=`-bound |
| `--keys-file <file>` | A file of keys: one `@i=<card>` per line, chunked cards as consecutive strings |
| `--seeds <seeds>...` | Seeds: ms1 plates or BIP-39 words, comma-separated, in order (seed 1 first) |
| `--seed-language <n>=<lang>` | The wordlist of seed n: `<n>=<lang>` (english, japanese, korean, spanish, chinese-simplified, chinese-traditional, french, italian, czech, portuguese) |
| `--accept-seed-language <n>` | Consent to use seed n in a language other than English |
| `--height <H>` | The tip's block height |
| `--time <T>` | The tip's median time past, unix seconds (any u32) |
| `--accept-tip` | Accept a tip whose height and time disagree with this release's anchor by more than 180 days |
| `--as <form>` | The output form Possible values: - descriptor: Split-chain, checksummed descriptors (receive, change) - md1: The member's md1 card (chunked if needed) - policy: A BIP 388 wallet policy for signer registration [default: descriptor] |
| `--open-slot` | Hand out an open member (some key spends sooner than the template allows) |
| `--accept-clamped` | Accept a lock clamped at its minimum by a shift, to-deadline or add-deadline (prints "spendable immediately by") |
| `--reorder-slot` | Accept a member whose paths open in another order than at slot 0 |
| `--lockup-slot` | Hand out a lock-up slot (no path spends without a lock) |
| `--lockup-no-window` | Accept a lock-up window shorter than --min-lead |
| `--accept-deadline` | Accept a deadline already past or closer than --min-lead |
| `--beyond-horizon` | Hand out a member beyond the heir's default scan |
| `--min-lead <L>` | The minimum lead, in days (default 30) [default: 30] |
| `--for-spend` | Print the member as the source of a spend: importdescriptors JSON (inactive, timestamp 0) on stdout, the spend recipe on stderr; skips the tip check, the deadline and horizon guardrails and the hand-out consents |
| `--accept-stub-mismatch` | Seat a plate whose policy-id stub is not this card's |
| `--accept-unconfirmed-seeds` | Use seeds nothing on the card confirms |
| `--min-deposit <sats>` | The minimum sensible deposit to print, in sat (replaces the reference figure) |
| `--compromised` | Declare this card's hot device lost or stolen (§7a): refuses unless --for-spend, which prints the destination rule |

`--as md1` prints the member's md1 card and a `md … --seat '@m=…'`
line per seated mk1 plate (with md's own `#k` ordinal where plates of
different cards share a chunk-set id); `--for-spend` refuses it. `--as policy`
sends a signer only a registrable policy, printing on stderr each
seat's xpub text and seat check and naming the seats filled only from
the card. On a card with a filled hot seat, a run without
`--compromised` ends with a one-line reminder to rerun with it if the
hot device was ever lost.

## `mr address`

Derive one address of a member, to check a receive or presigned-move
destination before using it. Every run prints "before the first
deposit to this set, check this address on a signer's screen". It
prints every hand-out refusal, the open one first; at a row other than
0 the open refusal names the slot-0 paths the row locks and the rows
that qualify instead. `--compromised` refuses at every row. An index
of 1000 or more warns: the heir's scan may not reach it.

### Synopsis

```sh
mr address [OPTIONS] --epoch <E> --slot <S> --index <I> --height <H> --time <T> <mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1>...` | The card's strings (one, or each chunk of a chunked card) |
| `--epoch <E>` | The epoch E |
| `--network <NETWORK>` | Network: main (default; `mainnet` is accepted too), signet, testnet or regtest [default: main] |
| `--slot <S>` | The slot S |
| `--index <I>` | The address index I |
| `--keys <mk1…\|records>...` | Keys: mk1 plates (a chunked plate's strings in one value, separated by spaces) or `[fingerprint/path]xpub` records, each optionally `@i=`-bound |
| `--keys-file <file>` | A file of keys: one `@i=<card>` per line, chunked cards as consecutive strings |
| `--seeds <seeds>...` | Seeds: ms1 plates or BIP-39 words, comma-separated, in order (seed 1 first) |
| `--seed-language <n>=<lang>` | The wordlist of seed n: `<n>=<lang>` (english, japanese, korean, spanish, chinese-simplified, chinese-traditional, french, italian, czech, portuguese) |
| `--accept-seed-language <n>` | Consent to use seed n in a language other than English |
| `--height <H>` | The tip's block height |
| `--time <T>` | The tip's median time past, unix seconds (any u32) |
| `--accept-tip` | Accept a tip whose height and time disagree with this release's anchor by more than 180 days |
| `--change` | The change chain (/c+1/*) instead of the receive chain |
| `--open-slot` | Hand out an open member (some key spends sooner than the template allows) |
| `--accept-clamped` | Accept a lock clamped at its minimum by a shift, to-deadline or add-deadline (prints "spendable immediately by") |
| `--reorder-slot` | Accept a member whose paths open in another order than at slot 0 |
| `--lockup-slot` | Hand out a lock-up slot (no path spends without a lock) |
| `--lockup-no-window` | Accept a lock-up window shorter than --min-lead |
| `--accept-deadline` | Accept a deadline already past or closer than --min-lead |
| `--beyond-horizon` | Hand out a member beyond the heir's default scan |
| `--min-lead <L>` | The minimum lead, in days (default 30) [default: 30] |
| `--accept-stub-mismatch` | Seat a plate whose policy-id stub is not this card's |
| `--accept-unconfirmed-seeds` | Use seeds nothing on the card confirms |
| `--min-deposit <sats>` | The minimum sensible deposit to print, in sat (replaces the reference figure) |
| `--compromised` | Declare this card's hot device lost or stolen (§7a): refuses at every row |

**Presigned moves** stay broadcastable until their inputs are spent and
do not protect coins past the epoch deadline: migrate to a fresh epoch
before leaving, and on return treat the transaction as live until its
coins are moved. Their fee is fixed at signing, so they need a fee
ladder or a P2A anchor. (`mr address --help` prints this advisory.)

## `mr current`

Find the nearest epoch whose every absolute lock, in slot S (default
0), is at least a lead L away, each kind in its own units (a block
counts 9 minutes). Locks set by `open` are ignored; a slot with no
other absolute lock is measured by the card's deadline functions, and
the answer then changes only the branch. Without `--slot`, each
own-wallet row is answered too (`wallet at slot s: epoch E`).

It also prints, for each path of the answered member with a relative
lock, `path <keys> opens about N days after each deposit confirms`,
warning when that wait is shorter than your lead, and the migration
rule: every row's funds move to the same slot of the new epoch, and
only an open row's go to slot 0.

It refuses when no epoch meets the lead: `no epoch of slot S meets
lead L; a lead of at most <L′> still reaches epoch <E>` while one
still meets `--min-lead`, else `this slot ends at <date>; move to a new
set on new origin paths`. Past the heir's default scan it answers the
last epoch of the scan and prints the lead achieved (`lead 9.4 years:
the most the heir's default scan covers`), or refuses `this slot ends
within the heir's scan: move to a new set` when that lead is below
`--min-lead`. An epoch-less card answers epoch 0 for any lead. At a
tip past 2038-01-19 a slot whose member carries a time lock has no
epoch, and `current` answers only the other slots. It takes no
`--compromised` and prints no reminder.

### Synopsis

```sh
mr current [OPTIONS] --height <H> --time <T> --lead <L> <mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1>...` | The card's strings (one, or each chunk of a chunked card) |
| `--height <H>` | The tip's block height |
| `--network <NETWORK>` | Network: main (default; `mainnet` is accepted too), signet, testnet or regtest [default: main] |
| `--time <T>` | The tip's median time past, unix seconds (any u32) |
| `--accept-tip` | Accept a tip whose height and time disagree with this release's anchor by more than 180 days |
| `--lead <L>` | The lead: how far every absolute lock must be from the tip (2y, 26w, 30d, 36h; a bare number is days; a block counts 9 minutes) |
| `--slot <S>` | The slot S (default 0; without it, each own-wallet row is answered too) |
| `--min-lead <L>` | The minimum lead: never offers a lead below it (default 30 days) [default: 30] |
| `--beyond-horizon` | Answer an epoch beyond the heir's default scan |

### Worked example

```sh
mr current mr1… --network testnet --height 1000000 --time 1900000000 --lead 5y
# tip = 1,000,000, ≈ 2030-03-17; this must be the current tip
# slot 0: epoch 1
# funds at slot 0 migrate to slot 0 of epoch 1; every row keeps its slot, …
```

## `mr export`

Export watch-only descriptors for a wallet or an heir: every member of
the chosen epochs and slots, each labelled with (e, s) and its unlock
heights or dates, as ready `bitcoin-cli scantxoutset` calls in windows of
1000 indexes (main calls over indexes k·1000 … k·1000 + 999, probe calls
over the top 100), batched at 1,000,000 scripts per call. The output
begins with each card's bundle list as a checklist. With `--seeds` it
also derives the bundle list's accounts (the cheap hot wallet included,
with its first address and restore text) and, unless
`--no-child-discovery`, the child discovery accounts. It never refuses
over a tip: the tip check is a warning.

### Synopsis

```sh
mr export [OPTIONS] <mr1>...
```

### Flags

| Flag | Purpose |
|---|---|
| `<mr1>...` | The card's strings (one, or each chunk of a chunked card) |
| `--card <mr1>` | Another card of the bundle, scanned with the same keys or seeds (a chunked card's strings in one value, separated by spaces); repeat for each card |
| `--network <NETWORK>` | Network: main (default; `mainnet` is accepted too), signet, testnet or regtest [default: main] |
| `--keys <mk1…\|records>...` | Keys: mk1 plates (a chunked plate's strings in one value, separated by spaces) or `[fingerprint/path]xpub` records, each optionally `@i=`-bound |
| `--keys-file <file>` | A file of keys: one `@i=<card>` per line, chunked cards as consecutive strings |
| `--seeds <seeds>...` | Seeds: ms1 plates or BIP-39 words, comma-separated, in order (seed 1 first) |
| `--seed-language <n>=<lang>` | The wordlist of seed n: `<n>=<lang>` (english, japanese, korean, spanish, chinese-simplified, chinese-traditional, french, italian, czech, portuguese) |
| `--accept-seed-language <n>` | Consent to use seed n in a language other than English |
| `--height <H>` | The tip's block height (with --time): the default scan, epochs 0 … e_hi |
| `--time <T>` | The tip's median time past, unix seconds (with --height) |
| `--horizon <D>` | The horizon in years (default: the card's horizon field, else 10) |
| `--epochs <a..b>` | Scan epochs a … b (inclusive) instead of the default range |
| `--exhaustive` | Scan every valid epoch |
| `--next <k[:target]>` | Emit window k of the run (k ≥ 1, or 0 with a target; at most 2,147,482), optionally narrowed to targets, repeated with one k: `[<digest prefix>:]<e>/<s>`, or a bundle entry (`held:84:0`, `C:84:0`, `A/24/0:86:0`) |
| `--history` | Check history, spent or not: the gap-20 address-index output and the Core rescan, instead of the quick scan |
| `--child <n>=<letter>/<12\|24>/<i>` | Declare given seed n to be the child `<letter>/<len>/<i>` a bundle entry names (e.g. `2=A/24/0`), as a `hot` kit's child plate reads |
| `--try-seatings [<K>]` | Export every seating of the undecided seats, up to K! of them (default K = 4, i.e. 24) |
| `--heir-file <file>` | Also write window 0's calls, headed by the set id, card digest, tip, horizon and epoch range, to this file: a fallback that needs no `mr` (it holds every descriptor, so every address) |
| `--no-child-discovery` | Leave out the child discovery scan (account 0 of each given seed's BIP-85 children 0 … 15, both lengths, four purposes) |

A card with an epoch axis needs one of the tip (`--height`, `--time`),
`--epochs a..b` or `--exhaustive`; an epoch-less card defaults to
`--epochs 0..0` and refuses any other range. Beside every probe call
`export` prints the ready `mr export <the same arguments> --next <k + 1>`
command: run it while a probe call finds any unspent output. Each card
prints the rule's `@i=` binding list after its set id and a seating
count with its scan time; seatings the card cannot decide (seats at one
origin path with nothing to tell their plates apart) are exported only
with `--try-seatings`, each labelled with its binding list and a ready
`member --for-spend` stem, and a count above K! is refused with its scan
time. `--next` may be repeated with one k, each value naming a target
(`--next 1:0/0 --next 1:held:84:0`): the run emits the union of the
targets' descriptors; two different k are refused. `--history` leaves
the child discovery accounts out; a discovery account prints its own
`--history --next 0:<entry>` command, and `--history`'s ready
next-window command keeps the run's targets. A seventeenth seed is
refused: run `export` once per group of at most 16 seeds.
`--heir-file` warns on stderr that the file holds every address of the
set. The file covers the whole run, so it is refused with a `--next`
target; with `--history` it holds window 0's main and probe calls and
then both history outputs.

### Worked example

```sh
mr export mr1… --network testnet --keys mk1… mk1… --height 1000000 --time 1900000000
# card 1: set id 0bcbf7c84ecc9a8b, card digest 01a0adbdf3d19c6e
# rule: @0=plate 1, @1=plate 2
# epochs 0 … 7 (the default scan: e_hi at this tip and horizon); …
# main call 1 of 1: 16 descriptors, 16,000 scripts, about 33 s
# bitcoin-cli scantxoutset start '[{"desc": …, "range": [0, 999]}, …]'
# if any unspent output: mr export <the same arguments> --next 1
```
